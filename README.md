# ПОЛКА — библиотека новелл

Одностраничное приложение для личной библиотеки и чтения новелл. Можно создавать произведения, добавлять главы, редактировать текст, менять размер шрифта и продолжать чтение с сохранённого места.

![Стек](https://img.shields.io/badge/stack-HTML%20%7C%20CSS%20%7C%20JavaScript-C9A24B)

## Возможности

- библиотека произведений с поиском, тегами и обложками;
- добавление, редактирование, удаление и изменение порядка глав;
- удобный режим чтения и изменение размера шрифта;
- сохранение прогресса чтения;
- адаптивный интерфейс и доступная навигация с клавиатуры;
- данные сохраняются локально в браузере (`localStorage`).

## Запуск

Для быстрого просмотра просто откройте `index.html` в браузере.

Для локального сервера, например через Python:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Хранение данных

Произведения, главы и прогресс чтения остаются в `localStorage` текущего браузера. Очистка данных сайта в браузере удалит библиотеку. В текущей версии нет сервера, авторизации или синхронизации между устройствами.

## Публикация на GitHub Pages

Загрузите содержимое репозитория в GitHub, затем в **Settings → Pages** выберите ветку `main` и папку `/ (root)`.
